DiskIOStress — 指令範例

各種測試的下法(CLI 直打 與 設定檔)· 把 /dev/sdX 換成你的目標裝置
注意事項 壓力測試(無斷電) 單一指令 Power-cycle(斷電) 用設定檔
⚠️ 所有寫入都會徹底破壞目標裝置上的資料。 下指令前務必確認 /dev/sdX 是正確的受測碟(lsblk -o NAME,TRAN,SIZE,MODEL 確認)。對 /dev/sda 會額外問 (y/n)。寫真實 block device 需要 sudo 與 root(O_DIRECT)。

1. 壓力測試(無斷電)

單執行緒 io_uring + O_DIRECT,write → read → verify。通吃 NVMe / SATA / USB。並發由 --qd 控制。

基礎 sequential 讀寫驗證

sudo ./build/DiskIOStress --workload=seq-verify --io-size=64K --qd=32 /dev/sdX

基礎 random 讀寫驗證

sudo ./build/DiskIOStress --workload=rand-verify --io-size=64K --qd=32 /dev/sdX

順序寫、重讀驗證兩次

sudo ./build/DiskIOStress --workload=seq-verify-2x --io-size=64K --qd=32 /dev/sdX

併發混合讀寫(同時讀+寫,比例可調)

sudo ./build/DiskIOStress --workload=concurrent-rw --rw-ratio=70 --io-size=64K --qd=64 --test-time=10m /dev/sdX

4 KiB 對齊 / 非對齊 / 混合(--align + --align-mode)

# 每道 command 都 4K 對齊
sudo ./build/DiskIOStress --io-size=4K --align=4K --align-mode=aligned   --qd=64 --pattern=addr /dev/sdX
# 每道 command 都偏移 1 個 sector(跨 4K 邊界,測 RMW)
sudo ./build/DiskIOStress --io-size=4K --align=4K --align-mode=unaligned --qd=64 --pattern=addr /dev/sdX
# 同一輪混合對齊/非對齊(deterministic,verify 不會誤判)
sudo ./build/DiskIOStress --io-size=4K --align=4K --align-mode=mixed     --qd=64 --pattern=addr /dev/sdX

每道 command 放進一個 align 大小的 slot(留間距,offset 的 command 不會跟鄰居重疊)。unaligned 預設偏移 1 個 sector(仍 512-aligned,O_DIRECT OK)。

控制 unaligned 的偏移量(--align-offset)

# 固定偏移 2K(每道 command 從 4K 邊界 +2048 起)
sudo ./build/DiskIOStress --io-size=4K --align=4K --align-mode=unaligned --align-offset=2K /dev/sdX
# 每道 command 隨機偏移(deterministic by seed,可重現)
sudo ./build/DiskIOStress --io-size=4K --align=4K --align-mode=unaligned --align-offset=random --seed=0x1234 /dev/sdX

大 command(1 MiB transfer)

sudo ./build/DiskIOStress --workload=seq-verify --io-size=1M --qd=16 /dev/sdX

Trim mixed(寫/驗證後 trim,下一輪重寫)

sudo ./build/DiskIOStress --workload=rand-verify --io-size=64K --qd=32 --trim /dev/sdX

限定範圍 / 限時 / 指定 seed(可重現)

sudo ./build/DiskIOStress --ranges=0-16G --test-time=600 --seed=0xABCD /dev/sdX

常用旗標:--qd --io-size --ranges --workload(seq-verify / rand-verify / seq-verify-2x / retention / concurrent-rw)--rw-ratio(concurrent-rw 用)--pattern(random/addr/zero/one/inc_dword…)--loops --test-time --seed --trim --no-direct。

2. 單一指令(一次性,參數為 16 進位)

資料指令走 io_uring(通吃 interface);rst/log/fwact 為 NVMe 專屬。

# 單筆寫 / 讀 / trim(lba len,16 進位)
sudo ./build/DiskIOStress /dev/sdX w 1000 8
sudo ./build/DiskIOStress /dev/sdX r 1000 8
sudo ./build/DiskIOStress /dev/sdX t 1000 100

# 循序 / 隨機 吞吐 profile(start end count)
sudo ./build/DiskIOStress /dev/sdX sw 0 100000 800     # 循序寫
sudo ./build/DiskIOStress /dev/sdX sr 0 100000 800     # 循序讀
sudo ./build/DiskIOStress /dev/sdX rw 0 100000 8       # 隨機寫
sudo ./build/DiskIOStress /dev/sdX rr 0 100000 8       # 隨機讀

# NVMe 專屬
sudo ./build/DiskIOStress /dev/nvme0n1 log 02          # SMART log
sudo ./build/DiskIOStress /dev/nvme0n1 rst 3           # controller reset x3
sudo ./build/DiskIOStress /dev/nvme0n1 fwact 1 1 2 fw.bin

3. Power-cycle(斷電完整性)

pcwrite 跑「寫 → 呼叫 power-hook 斷電 → 重開 → 掃描驗證 → loop」。先用 --power-hook-dry-run 不真的斷電把流程跑順。

先 dry-run 把 loop 跑順(不斷電)

sudo ./build/DiskIOStress /dev/sdX pcwrite --ranges=0-1G --io-size=64K --qd=32 \
     --cut-after=64M --cycles=2 --power-hook-dry-run

Sequential,只 graceful 斷電

sudo ./build/DiskIOStress /dev/sdX pcwrite --access=seq --ranges=0-4G \
     --graceful-ratio=1.0 --cut-after=256M --power-hook=./power-hook.usb-sim.sh

Random,全 ungraceful(突然斷電)

sudo ./build/DiskIOStress /dev/sdX pcwrite --access=random --ranges=0-4G \
     --graceful-ratio=0.0 --cut-after=256M --power-hook=./power-hook.usb-sim.sh

PLP 驗證(已完成的寫入必須存活,否則 FAIL)

sudo ./build/DiskIOStress /dev/sdX pcwrite --durability=plp --checkpoint-interval=256K \
     --access=random --graceful-ratio=0.0 --cut-after=256M --power-hook=./power-hook.usb-sim.sh

重開後手動單獨掃描

sudo ./build/DiskIOStress /dev/sdX pcscan
真實 ungraceful 需要會切 VBUS 的硬體 hook。power-hook.usb-sim.sh 只是 sysfs 邏輯斷線(不切電),足以跑流程但測不到真 cache 遺失。

4. 用設定檔(samples/)

每組測試都有對應的設定檔,CLI 旗標可覆蓋檔案內的值。

# 壓力測試(無斷電):--config 在前,device 在後
sudo ./build/DiskIOStress --config=samples/no-power/seq-verify.conf  /dev/sdX
sudo ./build/DiskIOStress --config=samples/no-power/4k-unaligned.conf /dev/sdX
sudo ./build/DiskIOStress --config=samples/no-power/trim-mixed.conf  /dev/sdX

# Power-cycle:pcwrite --config
sudo ./build/DiskIOStress /dev/sdX pcwrite --config=samples/with-power/plp-strict.conf
sudo ./build/DiskIOStress /dev/sdX pcwrite --config=samples/with-power/rand-ungraceful.conf --cycles=50

# 覆蓋設定檔的單一值(CLI > config)
sudo ./build/DiskIOStress --config=samples/no-power/rand-verify.conf --io-size=128K /dev/sdX
